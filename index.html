      ⚡ Connect your AI (how it really works)

      This is a browser-only, static page. It has no server, so outside agents cannot POST to it (GitHub Pages and other static hosts don't accept POST requests). These client-side options do work:

      From another tab or script on the same origin (e.g. the DevTools console of another tab of this site):

      const ch = new BroadcastChannel('atsmatrix-events');
ch.postMessage({ type: 'agent_event', source: 'my-bot', message: 'Found 3 papers on regolith sintering' });

      From a page that opened this one (window.open) or embeds it in an iframe:

      const w = window.open('https://YOUR-SITE/index.html');
// once it has loaded:
w.postMessage({ type: 'agent_event', source: 'my-bot', message: 'hello from outside' }, '*');

      Incoming messages are only written to the activity log, as plain text. They never trigger tool calls and never touch your keys.

      Paste one event (or an array of events) as JSON, for example {"source":"my-bot","message":"…"}

      A real webhook needs a small server that accepts POSTs and relays them to the browser over WebSocket or Server-Sent Events. README.md has a ~30-line Node sketch under "Real webhook". Until you run one, there's no endpoint to point outside agents at.
